B

Ja the Ghost is playing with rubber ducks. He has nnn piles of rubber ducks arranged in a row, where the iii-th pile contains aia_iai​ ducks. Quack the Duck gives Ja a strictly increasing sequence b1,b2,…,bnb_1,b_2,\ldots,b_nb1​,b2​,…,bn​ and commands him to make the piles a1,a2,…,ana_1,a_2,\ldots,a_na1​,a2​,…,an​ become exactly this sequence.

Ja performs the process in the following two stages:

  1. Ja may add any number of ducks to each pile.

    Formally, for each pile iii, he chooses a non-negative integer xix_ixi​ and replaces aia_iai​ with ai+xia_i+x_iai​+xi​.

  2. Ja may repeatedly swap two adjacent piles.

    Formally, he may perform the following operation any number of times, possibly zero: choose an index iii such that 1≤i≤n−11\le i\le n-11≤i≤n−1, and swap the values of aia_iai​ and ai+1a_{i+1}ai+1​.

A process is called valid if, after both stages end, the sequence of pile sizes is exactly b1,b2,…,bnb_1,b_2,\ldots,b_nb1​,b2​,…,bn​.

Find the minimum possible number of operations performed in the second stage among all valid processes. If there is no valid process, output −1-1−1.

注意到数据范围为2000，可以接受N2N^2N2的复杂度。

分析

我们只能增加a序列的数值，并且可以对a序列相邻元素进行交换使之和b序列相同，要求最小化交换次数。
由于b序列严格递增，且a序列元素只能变大不能变小，转换思路：
将b序列打乱，让b序列每个值和a对应（a中元素增大后，和打乱的b序列相同），此时再将b序列还原回来，交换次数实际上就是打乱后的序列b的逆序对。
考虑贪心算法：
对于每一个aia_iai​，我们找到第一个bj≥aib_j\ge a_ibj​≥ai​，将i和j匹配，令ci=jc_i=jci​=j（或者等于bjb_jbj​也行，因为b序列递增，统计逆序对时，j和bjb_jbj​等价）。如果找不到，则说明ai>max⁡(bj)a_i>\max(b_j)ai​>max(bj​)，此时输出-1。
随后统计c序列中的逆序对数就是最终答案。

Ja the Ghost is playing with rubber ducks again! There are nnn piles of rubber ducks arranged in a row from left to right. Initially, the iii-th pile contains aia_iai​ rubber ducks.

While the sequence aaa is not sorted in nondecreasing order, Ja must perform the following operation:

  • Choose two adjacent piles such that the left pile contains more ducks than the right pile. Ja swaps these two piles, and then adds the number of ducks in the new left pile to the new right pile.

    Formally, choose an index iii such that 1≤i<n1\le i \lt n1≤i<n and ai>ai+1a_i \gt a_{i+1}ai​>ai+1​. Then replace the adjacent pair (ai,ai+1)(a_i,a_{i+1})(ai​,ai+1​) with (ai+1,ai+ai+1)(a_{i+1},a_i+a_{i+1})(ai+1​,ai​+ai+1​).

For example, if two adjacent piles contain 777 and 333 rubber ducks, then after the operation they contain 333 and 101010 rubber ducks.

Ja may choose any index satisfying the condition above at each step. It can be shown that, regardless of his choices, the process eventually ends with the sequence sorted in nondecreasing order.

Ja wants the largest pile at the end of the process to contain as few rubber ducks as possible. Determine the minimum possible value of the largest pile.

又是一道序列题
虽然有minimum possible value of the largest pile，但是这并不是一道二分答案问题，而是一道简单的贪心题。

分析

考虑连续交换的变化：如果一个元素从i向右交换到j，那么最终aj=∑k=ijaka_j=\sum\limits_{k=i}^{j}a_kaj​=k=i∑j​ak​，也就是这一段的区间和。
我们最终需要将序列变成一个非严格递增的序列，也就是我们只需要最小化最后一个值（最后的值就是最大值）。而在一段连续交换的过程中，中间量的大小关系是不变的，但哪怕他们之间无序，交换成到有序的情况后，其最大值仍然不可能超过最右侧的值（因为最右侧的值是这一段的区间和，而其他的只是部分和）。
因此我们从左往右贪心求解。如果遇到逆序对，就交换两者。在若干次交换后，如果碰上更大的值，此时交换就终止了，答案需要更新为更大的值，再继续向右进行交换操作即可得出答案。

A binary string is a string consisting only of characters 000 and 111. The two characters 000 and 111 are called opposite values.

Consider a binary string ttt. Let ∣t∣|t|∣t∣ be the length of ttt. When ∣t∣≥2|t| \ge 2∣t∣≥2, for every 1≤i<∣t∣1 \le i \lt |t|1≤i<∣t∣, the characters tit_iti​ and ti+1t_{i+1}ti+1​ are adjacent.

A binary string ttt is called beautiful if it can be reduced to a string of length exactly 111 by applying the following operation any number of times, possibly zero:

  • Choose two equal adjacent characters, remove both of them, and insert one character with the opposite value in their place.

For example, the string 10001\mathtt{10001}10001 can become 1101\mathtt{1101}1101 by replacing the first adjacent pair 00\mathtt{00}00 with 1\mathtt{1}1. Then it can become 001\mathtt{001}001, then 11\mathtt{11}11, and finally 0\mathtt{0}0. Therefore, 10001\mathtt{10001}10001 is beautiful.

On the other hand, 111\mathtt{111}111 is not beautiful. After one operation, it becomes 01\mathtt{01}01, and then no operation can be applied.

You are given a binary string sss. Compute the number of non-empty beautiful substrings∗^{\text{∗}}∗ of sss.

∗^{\text{∗}}∗A string aaa is a substring of a string bbb if aaa can be obtained from bbb by the deletion of several (possibly, zero or all) characters from the beginning and several (possibly, zero or all) characters from the end.

分析

可以将相邻的2个1变成0，将相邻的2个0变成1。
考虑数值变化，前者Δ=0−2=−2\Delta=0-2=-2Δ=0−2=−2，后者Δ=1−0=1\Delta=1-0=1Δ=1−0=1，如果我们将权值增加1，即1的权值为2，0的权值为1，那么前者Δ=1−4=−3\Delta=1-4=-3Δ=1−4=−3，后者Δ=2−2=0\Delta=2-2=0Δ=2−2=0。
这样我们每一次消除操作后，权值要么不变，要么-3，要求最后只剩一个数，也就是最终权值为1或2。
显然，当这个序列总权值为3的倍数时，无论如何操作都不能只剩一位数。
此时我们得到了变成一位数的序列的必要条件。
很容易想到，如果一个序列01交替，那么无法进行任何操作。这肯定是不beautiful的。（实际上充分条件就是存在一个可以操作的位置，具体的证明很复杂，我也不会。。。）
设条件1为序列权值和模3非0，条件2为存在可操作位置。
现在考虑如何求beautiful的子串数量。
我们枚举右端点r，对于条件2，我们只需要记录最后一个可操作位置lastlastlast，那么满足条件2的区间就是左端点l≤lastl\le lastl≤last的区间，共有last个。显然，last在r增加时不会减少。
然后考虑条件1，我们的目的是要删去子区间里权值和为3的倍数的值。我们通过预处理一个权值前缀和模3的特殊前缀和prefprefpref，如果prefr=kpref_r=kprefr​=k，那么我们就要删去子区间里面prefprefpref同样为k的数量。记录从1到lastlastlast的prefprefpref的值的数量cntcntcnt，那么以r为右端点的beautiful子区间数量就是last−cntprefrlast-cnt_{pref_r}last−cntprefr​​。
