问题陈述

有一个 H×WH \times WH×W 网格，每个单元格包含一个整数 000 或 111 。
每个单元格中写入的整数的信息以长度为 WWW 的 HHH 字符串 S1,S2,…,SHS_1, S_2, \dots, S_HS1​,S2​,…,SH​ 的形式给出。如果 SiS_iSi​ 的第 jjj 个字符为“0”，则将 000 写入网格顶部起第 iii 行、左侧起第 jjj 列的单元格中；如果 SiS_iSi​ 的第 jjj 个字符是“1”，则在该单元格中写入 111 。

求写入的整数之和等于 KKK 的矩形区域的数量。
更正式地说，找到满足以下所有条件的整数四元组 (r1,c1,r2,c2)(r_1, c_1, r_2, c_2)(r1​,c1​,r2​,c2​) 的个数：

  • 1≤r1≤r2≤H1 \le r_1 \le r_2 \le H1≤r1​≤r2​≤H
  • 1≤c1≤c2≤W1 \le c_1 \le c_2 \le W1≤c1​≤c2​≤W
  • 在满足 r1≤i≤r2,c1≤j≤c2r_1 \le i \le r_2, c_1 \le j \le c_2r1​≤i≤r2​,c1​≤j≤c2​ 的所有整数对 (i,j)(i, j)(i,j) 中，写入从上数第 iii 行和从左数第 jjj 列的单元格中写入的整数之和等于 KKK 。

数据范围是500

分析：

需要求矩阵和恰好等于K的的数量，如果暴力枚举的话复杂度是O(N4)O(N^4)O(N4)。
但是考虑到数据范围是500，因此我们只需优化到O(N3)O(N^3)O(N3)即可，也就是优化一个维度。
预处理前缀和可以O(1)O(1)O(1)查询一段区间的和，这样就可以实现一个维度的优化。

思路：

以行为例，处理每一行的前缀和，随后用O(N2)O(N^2)O(N2)枚举[l,r][l,r][l,r]，固定统计l列到r列这一区间，这样从l列到r列的每一行可以用前缀和O(1)O(1)O(1)求出。
问题转化为了一个序列AAA，其中Ai=prer−prel−1A_i=pre_r-pre_{l-1}Ai​=prer​−prel−1​，求出序列AAA中区间和等于K的区间。
由于数据非负，可以采用滑动窗口来求，注意连续的0区间即可。（当然用哈希表更加简单且通用）

这里总结一下求区间和等于K的区间数量问题

  • 通用解法：哈希表记录前缀和为x的数量，则区间数量=∑hashK−prei\sum hash_{K-pre_i}∑hashK−prei​​
  • 若数据为正，可以采用简单的双指针法。
  • 若数据非负，可以在双指针基础上再增加一个指针用于记录0的区间。

问题陈述

有一个 N×NN \times NN×N 网格。最初，所有单元都被漆成白色。

按给定顺序处理 QQQ 查询。每个查询都是以下之一：

  • 输入 111 ：给出一个整数 RRR 。将网格顶部第 RRR 行中的所有单元格涂成黑色。
  • 输入 222 ：给出一个整数 CCC 。将网格左侧第 CCC -th 列中的所有单元格涂成白色。

处理完每个查询后，输出该点网格中黑色单元格的数量。

分析：

每次对行涂黑，对列涂白，求黑色格子数量。考虑每次操作对答案的贡献：

  • 行涂黑操作：增加涂黑前该行白格子数量
  • 列涂白操作：减少涂白前该列黑格子数量

思路：

假设当前时间为ttt，该行上一次涂黑的时间戳为ti−1t_{i-1}ti−1​，则该行涂黑前白格子数量为ti−1t_{i-1}ti−1​到tit_iti​这段时间进行列操作的数量。（当然需要去重）
列操作同理。
至于去重怎么实现？我们只需要记录上一次的操作即可，对该位置再次操作时覆盖上一次的时间即可。

那么我们的需求就是：对时间区间进行操作次数统计，以及对每次询问（即一个新的时间戳），更新该时间对应的操作。实际上就是单点修改+区间查询。因此使用树状数组就可以实现。

问题陈述

您将获得一个正整数 NNN (N≤1010N\le 10^{10}N≤1010)。
如果满足以下所有条件，我们将非空正整数序列 AAA 称为好序列：

  • AAA 的所有元素都是不同的。
  • AAA 的所有元素的乘积等于 NNN 。

序列的分数定义为序列中所有元素的总和。
求所有好序列的分数以 998244353998244353998244353 为模的总和。

分析：

需要一个序列乘积为N，且不重复，显然序列中可能的元素为N的所有因数，因此我们先把N的所有因数求出来并排序成序列BBB，时间复杂度O(Nlog⁡N)O(\sqrt{N}\log N)O(N​logN)
先不考虑排序问题
我们需要从BBB中选出j个数，使者j个数乘积为N。
定义Fx,jF_{x,j}Fx,j​：选择j个数且乘积为x的序列数量。
由于在序列BBB中选，且不能重复，因此这是一个01背包问题。
仅需考虑是否选择BiB_iBi​
状态转移方程为：

Fx×Bi,j=Fx×Bi,j+Fi,j−1F_{x\times B_i,j}=F_{x\times B_i,j}+F_{i,j-1}Fx×Bi​,j​=Fx×Bi​,j​+Fi,j−1​

由于最终需要统计分数（分数定义为序列中所有元素的总和），因此我们再定义Gx,jG_{x,j}Gx,j​为选择j个数且乘积为x的序列总分数。
在选择BiB_iBi​时，x×Bix\times B_ix×Bi​分数增加的部分为应该为在xxx的基础上，增加BiB_iBi​和对应区间数量的乘积。
状态转移方程为

Gx×Bi,j=Gx×Bi,j+G(i,j−1)+Fi,j−1×BiG_{x\times B_i,j}=G_{x\times B_i,j}+G_(i,j-1)+F_{i,j-1}\times B_iGx×Bi​,j​=Gx×Bi​,j​+G(​i,j−1)+Fi,j−1​×Bi​

最后再乘以对应区间长度的阶乘即可。

实际上由于不能重复，那么一个长度为L的区间最小乘积为L!L!L!，那么长度就不会超过13，因为13!≥101013!\ge 10^{10}13!≥1010。而根据题解，NNN最多也只有2304个因数。
因此复杂度约为O(2304×2304×14)O(2304\times 2304\times 14)O(2304×2304×14)
