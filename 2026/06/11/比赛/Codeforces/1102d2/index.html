题面

有 nnn 无限高的连通器排列成一圈。每个容器的底面积为 111 cm 2^22 ，并且在第 iii 个容器和第 (i mod n)+1(i \bmod n) + 1(imodn)+1 个容器之间在高度 hih_ihi​ cm处存在可忽略不计的体积的连接。对于每个容器 iii ，求在第 iii 个容器保持空的情况下可以放入这些容器中的最大总水体积（以cm 3^33 为单位）。

正式地，您将获得一个数组 h1,h2,…,hnh_1, h_2, \ldots, h_nh1​,h2​,…,hn​ 。如果满足以下条件，则非负整数的循环数组 w1,w2,…,wnw_1, w_2, \ldots, w_nw1​,w2​,…,wn​ 被称为良好：

  • 对于从 111 到 nnn 的每个 iii ，如果是 max⁡(wi,wi mod n+1)>hi\max(w_i, w_{i \bmod n + 1}) \gt h_imax(wi​,wimodn+1​)>hi​ ，则为 wi=wi mod n+1w_i = w_{i \bmod n + 1}wi​=wimodn+1​ 。换句话说，如果数组 www 的两个相邻元素的最大值超过了数组 hhh 的相应元素，则数组 www 的这两个相邻元素必须相等。

对于从 111 到 nnn 的每个 iii ，在 wi=0w_i = 0wi​=0 的条件下，输出所有好数组 w1,w2,…,wnw_1, w_2, \ldots, w_nw1​,w2​,…,wn​ 中的最大可能总和 w1+w2+…+wnw_1 + w_2 + \ldots + w_nw1​+w2​+…+wn​ 。

分析：

需要在保证i桶为空的情况下，求最多能加多少水。

easy version
可以接受O(N2)O(N^2)O(N2)处理，因此我们对于每一个i，顺时针和逆时针处理数据。
以顺时针为例，我们贪心地能加多少加多少，保证不会让身后的桶水量增加即可（不保证不影响前方），例如考虑第一个桶，序列h={3,4,2,6,1,5}，我们顺时针看（正向），得到的的序列为{0,4,4,6,6,6}，实际上就是转化为一个单调不减序列，也可看做单调栈。逆时针同理。
我们得到两个序列AAA和BBB对应顺时针和逆时针的单调不减序列，对于每一个位置，取两者的最小值就是最优情况。（因为最小值同时不会向左或右影响，且是贪心的最大值）


图中蓝色为顺时针的A序列，绿色为逆时针的B序列，红色圈出的为选择情况

hard version
通过上面的分析，我们假设最大的通道高度为HHH，对于两个贪心序列A和B，经过该位置时，后续的值全为HHH，因此我们取了最小值之后，对于位置i，其最终答案为在顺时针方向，选择了A序列到H的部分，以及逆时针防线，选择了B序列到H的部分。
如果我们从H处断开，展开成一条链，那么就是一段单调不减的后缀和一段单调不增的前缀。
因此我们预处理出来即可。
